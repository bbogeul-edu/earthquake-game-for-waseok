# 지진에서 살아남기

와석초등학교 학생용 지진 안전교육 인터랙티브 게임 (태블릿용).
나른한 5교시에 지진이 나고, 우리 반 교실에서 운동장까지 대피하며 다친 친구를 돕는 이야기예요.
"지진해일에서 살아남기"(v1.3.0)와 같은 엔진을 쓰고, 3D 대피 미니게임을 더했어요.

빌드 과정이 없는 정적 사이트라서 Vercel에서 Framework Preset을 "Other"로 두고 그대로 배포하면 돼요.

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 모양 (미니게임 화면 포함) |
| `engine.js` | 게임 엔진: 대본 실행, 하트·세이브, 뒤로/건너뛰기/다시, 소리, 랭킹 |
| `story.js` | 이야기: 등장인물, 카드뉴스, 안전수칙, 대본 |
| `quake3d.js` | 3장 3D 대피 미니게임 |
| `school.js` | 학교 건물 배치와 반별 공식 대피로 (`tools/build_school.py`가 만들어요) |
| `school.src.js` | `school.js`의 원본 (대피로 표는 여기서 고쳐요) |
| `img/` | 배경 그림, `img/face/` 인물 얼굴 |
| `supabase/schema.sql` | 랭킹 표 |

## 3D 대피 미니게임
- 시작 화면에서 고른 학년·반의 교실에서 출발해, 학교 공식 대피 계단까지 1인칭으로 걸어가요.
- 건물 배치는 [와석초 3D 배치도](https://waseok.github.io/waseok-3d-map/?v=2)의 `data/rooms.json`과 같아요.
- 반별 대피로는 2026학년도 교실배치도(안)의 빨간 화살표를 옮겨 `school.src.js`의 `put(...)` 줄에 적어 두었어요.
- 실수(창문 가까이, 떨어진 물건 밟기, 승강기, 흔들릴 때 머리 보호 안 함, 계단 뛰기)는 하트 대신 50점씩 깎고, 모두 합쳐 최대 200점까지만 깎아요.
- 1층 교실(1-6, 1-7)은 계단 없이 별관 출구까지 가고, 4장도 복도에서 일어나요.

### 교실 배치가 바뀌면
1. 3D 배치도 저장소의 새 `data/rooms.json`을 받아요.
2. `python tools/build_school.py <rooms.json 경로>` 로 `school.js`를 다시 만들어요.
3. 대피로가 바뀌었으면 `school.src.js`의 `put('중앙', '6-1 6-2 …')` 줄을 고친 뒤 2번을 다시 해요.

## 랭킹 보드 (Supabase)
지진해일 게임과 같은 Supabase를 써요. 게임별로 `game` 칸(`earthquake`)으로 나뉘어요.

**이 게임을 처음 올릴 때 한 번:** Supabase 대시보드 → SQL Editor → `supabase/schema.sql` 전체를 붙여 넣고 Run.
3D 감점을 저장하는 `mini` 칸과 새 점수 규칙이 들어가요. (지진해일 게임 기록은 그대로예요)

점수 = 기본 1000 + 남은 하트×200 − 틀린 횟수×100 − 힌트×50 − 3D 대피 감점 (최고 1600점)

## 배경 그림
